\section{Concurrency}

\path{server/src/domain/domain.test.ts} registers 400 distinct users into a contest of 200 seats. The coverage run recorded that case at about 87 seconds. The result is exactly 200 seats and no duplicate seat.

The write is a filtered update: a seat is inserted only while \texttt{reserved < capacity}, and a unique partial index rejects a second active seat for the same user. Two requests cannot both observe spare capacity and both commit. The same file checks that a stale judge claim token does not apply a second verdict, and that a first solve is awarded once.

The demo contest Last seat has capacity 1 and registration open. Two browsers register. One is seated and one is waitlisted. That is the same filter, shown with a room of one.

\section{Deployment}

Not a static host. The API holds Socket.IO connections, the judge is a Redis consumer that calls \texttt{docker run}, and Mongo is a replica set.

The shape, when the account has the allowance, is one Ubuntu or Amazon Linux \texttt{t3.micro}, a public subnet, a public IP, 20~GB gp3, and 1~GB of swap on the root disk. The security group allows port 22 from the presenter's address and port 80, and nothing else. Mongo, Redis, and Mailpit stay on localhost. Caddy serves \path{client/dist} and proxies \texttt{/api}, \texttt{/socket.io}, \texttt{/health}, and \texttt{/metrics} to \texttt{127.0.0.1:4000}. Server, judge, and agent are systemd units. The judge uses that machine's Docker socket. \texttt{python:3.12-alpine} is pulled during setup so the live submit is not a cold pull. \path{CLIENT_ORIGIN} is \texttt{http://<public-ip>}. Gemini keys are in the unit environment, not in git. After setup, \path{scripts/demo-harden.mjs} is pointed at the public URL. The instance is stopped after the slot.

That launch was not done. The signed-in account would have been billed. The ten-minute path runs on this PC, which has the same compose stack, the same seed, Mailpit, and the saved hardening files. \path{deploy/README.md} is the checklist for an eligible account, including the stop command.
