\begin{frame}{Problem and roles}
\begin{itemize}
\item A contest platform: seats, submissions, a sandbox judge, and one hardening agent.
\item Participants sit and submit. Setters author problems. The admin runs the contest.
\item The agent proposes tests. A person publishes.
\item Demo accounts use the password \texttt{codeclash}. Aarav submits. Meghna opens the saved run.
\end{itemize}
\end{frame}

\begin{frame}{Requirements}
\begin{itemize}
\item A seat exists only while \texttt{reserved < capacity}. 400 users, 200 seats, exactly 200 seated.
\item A submission gets one verdict. A stale claim does not score it again.
\item Six languages. The compiler can write. The run user cannot.
\item Signup is a six-digit code. A participant who opens Admin is turned away.
\end{itemize}
\end{frame}

\begin{frame}{Architecture}
\begin{itemize}
\item React client, Express API, Socket.IO, Mongo replica set, Redis streams.
\item Judge and agent are separate processes. The judge calls \texttt{docker run}.
\item One machine. Mongo, Redis, and Mailpit stay on localhost.
\item Caddy on port 80. No load balancer, no NAT gateway, no RDS.
\end{itemize}
\end{frame}
